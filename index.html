통합의료정보시스템
에이전트 플랫폼

폐쇄망 병원 환경에서 통합의료정보시스템과 연동되는 에이전트 생태계를 구축합니다. 통합의료정보시스템 에이전트로 업무 워크플로우를 시각적으로 저작·실행하고, 일산병원 데이터허브 MCP 서버로 의료기록·부서·검사 등 도구를 에이전트에 안전하게 노출합니다.

주요 기능

  • 에이전트 저작·실행 캔버스 기반 빌더로 GraphSpec을 내보내고, hermes-chat 멀티에이전트로 병원 업무 흐름을 실행합니다.
  • 도구·데이터 연동 Streamable HTTP MCP · Oracle(통합의료정보시스템) · Tableau(DW) 연동으로 조회·분석 도구를 에이전트에 연결합니다.
  • 인증·거버넌스 사번 로그인, API 키 스코프, Redis 세션, PHI 보존기간 파기 정책으로 폐쇄망에서의 접근 통제와 감사 가능성을 맞춥니다.
  • 노코드 도구 레지스트리 데이터허브에서 도구를 등록·관리하고, 온프레미스 LLM·Hermes와 함께 워크플로우에 노출합니다.
