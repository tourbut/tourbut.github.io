# tourbut.github.io

신성철(tourbut) 개발자 포트폴리오 사이트입니다.  
라이브: **https://tourbut.github.io/**

## 구성

| 경로 | 설명 |
|------|------|
| `index.html` | 단일 페이지 포트폴리오 (소개 / 경력 / 프로젝트 / 기술 / 수상·자격 / 연락) |
| `css/styles.css` | 다크 테마 스타일 |
| `js/main.js` | 모바일 메뉴, 연도, 스크롤 섹션 하이라이트 |

## 수정 방법

1. 이 저장소를 클론합니다.
2. `index.html`의 해당 섹션을 수정합니다. (경력·프로젝트·연락처 등)
3. 스타일은 `css/styles.css`, 인터랙션은 `js/main.js`에서 조정합니다.
4. `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 반영합니다.

```bash
git clone https://github.com/tourbut/tourbut.github.io.git
cd tourbut.github.io
# 편집 후
git add -A && git commit -m "Update portfolio" && git push
```

## GitHub Pages

- **Source**: `main` 브랜치 / 루트 (`/`)
- **URL**: https://tourbut.github.io/

설정 확인: Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`
